# Кухни для Кухни: демоверсия главной страницы

Концепт новой главной страницы для [kdk161.ru](https://kdk161.ru/). Подготовлен для аудита и демонстрации.

**Демо:** https://yozzi05.github.io/kdk161-demo/

## Что показывает демо

- Первый экран с понятным предложением и основным действием «Рассчитать мою кухню».
- Выбор между серийной кухней и индивидуальным проектом. Форма открывается с уже выбранным направлением.
- Реальные проекты из галереи компании с просмотром фото.
- Объяснение стоимости и шкала стартовых цен серийных моделей в ₽ за погонный метр.
- Порядок заказа, блок доверия со ссылкой на отзывы на Яндекс Картах, FAQ.
- Двухшаговая форма предварительного расчёта.

## Важно

- Это **демоверсия**. Форма ничего не отправляет и не сохраняет.
- Фотографии, цены и условия взяты с kdk161.ru 22.10.2026. Перед публикацией их нужно сверить с компанией.
- Страница закрыта от индексации (`noindex`).

## Структура

- `index.html`: страница целиком (HTML, CSS, JS без сборки).
- Данные компании, проектов, цен и FAQ хранятся в блоке `<script id="site-data" type="application/json">`. Их можно менять без правки разметки.
- `assets/logo-kdk.jpg`: оригинальный логотип с kdk161.ru.
- `img/`: фотографии проектов и визуализации моделей с kdk161.ru.
